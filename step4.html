Step 4: Advanced Tools

After you get comfortable using GG here are some tools to introduce you into creating your own scripts!

Scripts are coding written in Lua using GG specific functions to automate mods for you. They can be structured as individual mods or full blown mod menus, so here is some of our tools below

1. GG Matrix IDE - Here you will find a custom coding interface tailored to GG Lua! We Recommend starting here as there is injectable working mods and each line is explained in detail. Also a great place to write your scripts, and works beautifully on desktop.

2. GG Script Generator V1 - Here is an amazing script generator to making your coding workload light! This tool lets you input searches, edits, and more to create a fully working script just add some numbers and press go to recieve a full script!

3. GG Script Encryptor - This encrypts your script making the code unreadable to most users. Perfect for keeping your hard work private!

4. More Tools on the way! Keep an eye out for new tools and resources such as mod shop where you can buy our mods but not encrypted so you can reuse for your very own scripts, GG Script Gen V2 and much much more!
