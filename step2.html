Step 2: Setup Process

Heres how to get GG and virtual space set up!

In your files manager locate the two APKs you installed from the previous page (GG & KGO) and install them

Some phones are incompatible so if your attempts are unsuccesful try other virtual spaces or invest in a Google Pixel phone for max compatibility

What is Virtual Space you may be asking?

Virtual space apps (like KGO PRO) create a sandboxed environment where you can run apps independently from the main system. On non-rooted phones, GameGuardian can't access the system memory directly, so a virtual space is used to simulate root access, allowing GG to function. It tricks the system into thinking apps are running with elevated privileges without needing actual root access, making it essential for running GameGuardian on unrooted devices

Once you have the APK's downloaded heres how to get it running!

Step 1: Open the GG titled SW (Software Acceleration) then, select no root and it will install a third GG application with a unique name.

Step 2: Open KGO PRO Virtual and clone both CPM or target game and the new third GG application so both are showing in the KGO "Homescreen"

Step 3: Run GG in virtual space and if you get daemon errors 90% of the time its phone compatibility issues, but if you see none your most likely good!

Step 4: Allow any permissions GG requests so it can run properly and launch the game with GG in the backround (as a floating icon)

Step 5: Once in the game open GG if no errors congratulations you are successfully running GG on a non rooted phone!
